# Roadmap

## 0.1.x — harden the reference

- migration framework and explicit schema compatibility receipts;
- more parser and SQLite fault-injection tests;
- signed release attestations and published checksums;
- accessibility and browser compatibility audit for the local dashboard;
- independent LearnPack conformance corpus.

## 0.2 — broaden without overclaiming

- additional explicit-import adapters with consent receipts;
- a registry of reviewed, typed compilation templates;
- conflict-aware memory supersession beyond version 1;
- pluggable deterministic pattern miners with calibrated abstention;
- content-addressed packs and optional external signatures.

## Research only

Real desktop observation and action execution require a separate safety architecture, platform-native consent indicators, sandboxing, capability revocation, transaction/rollback semantics, and user studies. They are not scheduled or promised by this roadmap.
