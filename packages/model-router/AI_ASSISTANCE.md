# AI assistance disclosure

Model Router was implemented with AI-assisted coding and review under human direction.

## AI-assisted work

- translated the public routing requirements into explicit data and state contracts;
- drafted the registry, scoring engine, SQLite queue, CLI, examples, tests, and documentation;
- checked hard constraints, idempotency, retries, lease recovery, evidence gates, and public boundaries;
- prepared reproducible verification and release material.

## Human role

The human owner selected the public roadmap item, authorized a standalone public repository, required public-only work, and remains responsible for accepting releases and deciding production adaptations.

## Boundaries

No private source code, secret, customer data, production topology, or proprietary prompt was used. All agents, tasks, costs, owners, commits, events, and artifacts in the examples are synthetic. AI output is not proof: deterministic tests and CI are the release evidence.
