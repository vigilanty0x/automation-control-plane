# AI Assistance

AI tools assisted with defensive review, implementation, adversarial regression tests, and documentation for Worktree Conflict Visualizer.

The generated suggestions were constrained to this public package's stated purpose: Find overlapping declared paths across bounded worktree inventories and emit deterministic Mermaid evidence. Maintainers remain responsible for reviewing changes, validating behavior, and deciding what to release.

No credentials, private source code, private service data, or live user data are required by the package or its examples. AI-generated output is not a security guarantee; the test suite and trust model in README.md are the reproducible evidence.
