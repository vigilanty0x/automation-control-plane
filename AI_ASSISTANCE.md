# AI assistance disclosure

Agent Worktrees was implemented with AI-assisted coding and review under human direction.

## AI-assisted work

- translated the public worktree requirements into explicit ownership, state, evidence, and cleanup contracts;
- drafted the Python package, SQLite registry, bounded Git service, JSON CLI, tests, examples, and documentation;
- exercised real disposable repositories for conflicts, retries, dirty work, unowned changes, missing worktrees, integration, and cleanup;
- prepared repeatable local and GitHub Actions verification.

## Human role

The human owner selected the public roadmap item, authorized a standalone public repository, required public-only content, and remains responsible for accepting releases and production adaptations.

## Boundaries

No private source code, secret, customer record, production topology, or proprietary prompt was used. Repository names, agents, owners, commits, tasks, and artifacts in examples and tests are synthetic. AI output is not treated as proof; deterministic tests and CI are the release evidence.
